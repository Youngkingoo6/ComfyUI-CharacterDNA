# CharacterDNA 三庭五眼与七档比例标准

## 七档统一坐标

第一版采用“相对标准百分比”而不是未经样本验证的统计标准差。所有具有正基准值的比例统一按标准值的百分比划分：

| DNA | 名称 | 标准值倍数 |
|---:|---|---:|
| -1 | 极低 | 70% |
| -0.6667 | 明显偏低 | 80% |
| -0.3333 | 偏低 | 90% |
| 0 | 标准 | 100% |
| +0.3333 | 偏高 | 110% |
| +0.6667 | 明显偏高 | 120% |
| +1 | 极高 | 130% |

眼角角度以 0° 为中心，七档分别为 `-9°、-6°、-3°、0°、+3°、+6°、+9°`。

这套档位是 CharacterDNA 的设计坐标，不是“美貌等级”。后续积累足够标准正面样本后，可以把百分比边界替换为人群均值与标准差，同时保持 DNA 的 `-1～+1` 接口不变。

## 三庭

标准定义：

```text
发际线 → 眉骨 = 脸长的 1/3
眉骨 → 鼻底   = 脸长的 1/3
鼻底 → 下巴   = 脸长的 1/3
```

单段占脸长比例的七档为：

```text
0.2333, 0.2667, 0.3000, 0.3333, 0.3667, 0.4000, 0.4333
```

InsightFace 106 不包含稳定发际线点，因此当前分析器只能输出中庭、下庭及其中庭/下庭比。上庭保留为设计与 Prompt 标准，不能作为已测量结果。若未来加入发际线分割模型，再启用完整三庭评分。

## 五眼

标准定义：

```text
脸宽 ≈ 5 × 平均单眼宽
内眦间距 ≈ 1 × 平均单眼宽
左眼尾至左侧脸缘 ≈ 1 × 平均单眼宽
右眼尾至右侧脸缘 ≈ 1 × 平均单眼宽
```

对应的标准比值：

```text
平均眼宽 ÷ 脸宽 = 0.20
脸宽 ÷ 平均眼宽 = 5.00
内眦间距 ÷ 平均眼宽 = 1.00
单侧外缘距离 ÷ 平均眼宽 = 1.00
```

眼宽/脸宽七档为：

```text
0.14, 0.16, 0.18, 0.20, 0.22, 0.24, 0.26
```

眼距/眼宽和侧缘/眼宽七档为：

```text
0.70, 0.80, 0.90, 1.00, 1.10, 1.20, 1.30
```

当前侧脸缘使用 106 点轮廓的横向极值，是可用但暂定的二维近似，分析结果会明确标记 `provisional`。

## 其他五官的统一方法

每个特征必须记录：

1. 稳定分母，例如脸宽、平均眼宽、鼻宽或上唇厚度。
2. 标准比值。
3. 七档目标值。
4. 测量容差。
5. 中英文 Prompt 模板。

当前已落地的 11 项包括眼宽、眼睛开合、眼距、眼角倾斜、眉眼距离、鼻宽、鼻长、嘴宽、上下唇厚度和唇峰深度。每一项的实际基准会显示在词库管理面板的 `Standard basis / 标准基准` 中。

## Prompt 规则

非零 DNA 同时输出语义与数值：

```text
slightly wide-set eyes, inner-canthal distance approximately 1.100 times average eye width
偏宽的眼距，内眼角间距约为平均眼宽的1.100倍
```

DNA 为 0 时不输出，保持当前极简规则。Composite 可以合并语义，但不得删除数值比例锚点。
